# Электронная очередь на родительском собрании

Next.js 14 (App Router) + Tailwind CSS + Firebase Realtime Database.

| Роут | Для кого | Что делает |
|---|---|---|
| `/teacher/[subjectId]` | Учитель, сенсорная панель | Статус, таймер 5 мин, звонок и красное мигание на 00:00, список очереди, кнопки «Начать встречу», «Пригласить следующего», «Завершить встречу» |
| `/queue/[subjectId]` | Родитель, телефон | Форма «Имя и Фамилия ученика», номер, «перед вами N», ожидание (N × 5 мин), звук и зелёное пульсирующее «ВАША ОЧЕРЕДЬ!» |
| `/` | Все | Ввод идентификатора предмета и переход на нужный экран |

`subjectId` — любая строка без пробелов и символов `. # $ [ ]` (например `math`, `physics-214`).

## Запуск

```bash
npm install
cp .env.local.example .env.local   # заполните ключи Firebase
npm run dev
```

1. В [Firebase Console](https://console.firebase.google.com) создайте проект и **Realtime Database**.
2. Добавьте Web-приложение и скопируйте конфиг в `.env.local`.
3. Вставьте содержимое `database.rules.json` во вкладку **Rules** базы.
4. (Необязательно) Добавьте названия предметов, импортировав JSON в `subjects/`:

```json
{
  "math":    { "name": "Математика", "teacher": "Иванова А.П.", "room": "Каб. 214" },
  "physics": { "name": "Физика",     "teacher": "Сидоров Н.К.", "room": "Каб. 305" }
}
```

Без этого на экранах показывается сам `subjectId`.

## Структура базы данных

```
subjects/
  {subjectId}/
    name, teacher?, room?

queues/
  {subjectId}/
    counter: 7                      # последний выданный номер (атомарно, через транзакцию)
    timer:
      endsAt: 1760090400000 | null  # серверное время окончания встречи
      duration: 300                 # регламент, секунд
    entries/
      {pushId}/
        name: "Алия Нурланова"
        number: 3
        joinedAt: 1760090000000     # ServerValue.TIMESTAMP
        status: "waiting" | "current" | "done"
        invitedAt?: 1760090300000
```

- **Место не теряется при обновлении страницы:** `pushId` записи родителя хранится в `localStorage` (`queue:{subjectId}`), при загрузке страница находит запись в базе.
- **Таймер синхронный:** хранится `endsAt` в серверном времени, клиенты вычитают `.info/serverTimeOffset`. Перезагрузка панели не сбрасывает отсчёт.
- **«Пригласить следующего»** — одна транзакция: текущий → `done`, первый `waiting` (по `number`) → `current`, `timer.endsAt = null`.

## Основные функции (`lib/queue.ts`)

`joinQueue`, `leaveQueue`, `inviteNext`, `finishCurrent`, `startMeeting`, `resetQueue`. Подключение к Firebase — `lib/firebase.ts`, подписка в реальном времени — `hooks/useQueue.ts`.

## Звук

Файлы `public/bell.mp3` (звонок учителя) и `public/notification.mp3` (сигнал родителю) — простые сгенерированные тоны, замените на свои под теми же именами.

Браузеры разрешают звук только после касания страницы. Поэтому:
- учитель разблокирует звук нажатием «Начать встречу» / «Пригласить следующего»;
- родитель — нажатием «Встать в очередь».

Если страницу родителя перезагрузили, а звук заблокирован, появится жёлтая кнопка «Нажмите, чтобы включить звук». Также срабатывает вибрация (где поддерживается).

## Безопасность

Правила в `database.rules.json` — **демонстрационные**: чтение и запись в `queues/` открыты, чтобы родителям не требовался вход. Для боевого использования подключите Firebase Auth (анонимный вход для родителей, учителя — по e-mail) и ограничьте запись: родителю — только создание своей записи, учителю — `timer`, смена статусов и сброс.
